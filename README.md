## Project Overview

This repository contains a manual QA training project based on testing the **ListBoxer desktop application** as part of a software testing course.

ListBoxer is a desktop application designed for creating, modifying, saving, opening, deleting, filtering, and sorting alphanumeric lists.

The project was completed as a team training assignment and covered different stages of the manual QA process, including requirements analysis, test documentation preparation, test execution, defect reporting, requirements traceability, and final test reporting.

## Selected Findings

During my testing, defects were identified in several important areas, including:

- Data integrity when opening saved lists
- Descending sorting
- Undo behavior
- Clear List behavior
- Keyboard shortcuts
- Contextual Help

Examples of reported issues include:

- Missing records after opening a saved list
- Incorrect list sorting in descending order
- Undo not fully restoring the previous application state
- Clear List remaining disabled in certain scenarios
- Keyboard shortcuts performing incorrect actions
- F1 opening Windows Help instead of ListBoxer contextual help

---

## Project Result

The final team testing results showed that the application still contained defects affecting important functionality.

Based on the final Test Summary Report, the team recommended postponing the release until critical and major defects were resolved.

## Відібрані знайдені проблеми

Під час мого тестування були виявлені дефекти у важливих частинах застосунку, зокрема:

- Цілісність даних під час відкриття збережених списків
- Сортування за спаданням
- Робота Undo
- Робота Clear List
- Гарячі клавіші
- Контекстна довідка

Приклади знайдених проблем:

- Втрата запису після відкриття збереженого списку
- Некоректне сортування списку за спаданням
- Undo не повністю відновлює попередній стан застосунку
- Clear List залишається неактивною в окремих сценаріях
- Гарячі клавіші виконують неправильні дії
- F1 відкриває Windows Help замість контекстної довідки ListBoxer

Фінальні результати командного тестування показали, що застосунок все ще містив дефекти, які впливали на важливу функціональність.

Відповідно до фінального Test Summary Report, команда рекомендувала перенести реліз до усунення критичних та значних дефектів.
