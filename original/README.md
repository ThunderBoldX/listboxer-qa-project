# Original Project Artifacts

This folder contains the original QA documentation created during the ListBoxer training project as part of a software testing course.

The project was completed as a team assignment. The artifacts are preserved in their original form and language to demonstrate the actual testing process and documentation created during the course.

## Included Artifacts

- Requirements
- Requirements Analysis
- Test Plan
- Checklist
- Requirements Traceability Matrix
- Test Summary Report
- Jira export with Test Cases
- Jira export with Bug Reports

## My Contribution

During the project, I participated in:

- Requirements analysis
- Test case creation and execution
- Checklist creation and execution
- Bug reporting in Jira
- Functional testing
- Negative testing
- Testing of list creation, modification, saving and opening
- Testing of UI controls
- Testing of Add to List and Clear List functionality
- Testing of Undo functionality
- Testing of keyboard shortcuts and Help functionality
- Contribution to the Test Plan
- Contribution to the Test Summary Report
- Working with the Requirements Traceability Matrix

The original documentation may contain contributions from other team members because this was a collaborative training project.

For a cleaned and English-language portfolio version, see the `/english` folder.
