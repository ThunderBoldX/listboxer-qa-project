# ListBoxer QA Project Summary

## Project Overview

ListBoxer is a desktop application designed for creating, modifying, saving, opening, deleting, filtering, and sorting alphanumeric lists.

This project was completed as part of a software testing course in a team environment. The goal of the project was to practice the complete manual QA process using requirements, test documentation, Jira, and structured test execution.

## My Role

**Role:** QA Trainee / Manual QA

During the project, I participated in the analysis, preparation, execution, and documentation of testing activities.

My responsibilities included:

- Reviewing and analyzing requirements
- Creating and executing test cases
- Creating and executing checklist-based tests
- Reporting defects in Jira
- Verifying application behavior against requirements
- Contributing to the Test Plan
- Contributing to the Test Summary Report
- Working with the Requirements Traceability Matrix
- Analyzing testing risks and application invariants

## Areas I Tested

I worked with the following parts of the application:

- List creation and modification
- Saving and opening lists
- List deletion
- Add to List functionality
- Clear List functionality
- Sort Order controls
- Alphabetic and Numeric mode controls
- Undo functionality
- Contextual Help
- Keyboard shortcuts

## Key Findings

During testing, defects were identified in several important areas of the application, including:

- Data integrity when saving and opening lists
- Descending sorting
- Undo behavior
- Clear List behavior
- Keyboard shortcuts
- Contextual Help

Some of these defects affected key application functionality and were considered significant for release readiness.

## Project Result

Based on the testing results, the project team recommended postponing the release until critical and major defects were resolved.
